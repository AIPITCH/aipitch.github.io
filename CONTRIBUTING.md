# Contributing an AIPITCH project

Consortium members are invited to add software, datasets, publications and other reusable project outputs to the **Our contributions** catalogue.

## Add a contribution

1. Fork this repository and create a branch.
2. Copy `_projects/_template.md` to `_projects/<short-project-name>.md`.
3. Complete every front-matter field and replace the sample sections with a clear, accessible description of your work.
4. Preview the website locally with `bundle exec jekyll serve`.
5. Open a pull request. Include a link to the contribution and identify the AIPITCH consortium member responsible for it.

Please write for a broad cybersecurity audience, not only for the software’s maintainers. Do not copy material that the project is not permitted to republish. Links should use HTTPS.

## Review checklist

- The contribution was produced within or directly supports AIPITCH.
- The named consortium member has approved publication.
- The summary explains the value of the work in one sentence.
- Technical claims, status and license information are current.
- Public source, documentation or publication links work.
- No credentials, personal data or confidential project information are included.
