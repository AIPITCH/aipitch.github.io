## Vulnerability intelligence for AI assistants

VulnMCP connects Model Context Protocol-compatible AI assistants to vulnerability information. It exposes vulnerability intelligence through a consistent set of tools, helping assistants retrieve and work with security data without requiring a bespoke integration for every client.

The software is developed by **CIRCL (Computer Incident Response Center Luxembourg)** as part of its contribution to AIPITCH and is maintained openly on GitHub.

## Why it matters

Cybersecurity analysts need accurate, relevant vulnerability context while investigating threats and deciding what to prioritise. Making that information available through the Model Context Protocol allows AI-assisted workflows to incorporate vulnerability intelligence while keeping the integration reusable and transparent.

VulnMCP complements the AIPITCH toolkit by making operational security knowledge more readily available to AI-enabled cyberdefence tools.

## Get involved

The project is open source. You can review the implementation, report issues and propose improvements in the [VulnMCP GitHub repository](https://github.com/vulnerability-lookup/VulnMCP). Consult the repository README for current setup, configuration and usage instructions.
