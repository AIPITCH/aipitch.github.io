## One gateway for machine-learning services

ML-Gateway helps applications and analysts use machine-learning models without having to integrate separately with every model implementation. It provides a common gateway between clients and model-serving backends, making AIPITCH capabilities easier to integrate into operational workflows.

The software is developed by **CIRCL (Computer Incident Response Center Luxembourg)** as part of its contribution to AIPITCH and is maintained openly on GitHub.

## Why it matters

Cybersecurity teams need to turn experimental models into dependable, reusable services. A shared gateway reduces integration effort and gives model consumers a stable entry point while allowing the services behind it to evolve.

ML-Gateway contributes to the project’s goal of connecting complementary AI capabilities into a practical toolkit for national and enterprise cyberdefence teams.

## Get involved

The project is open source. You can review the implementation, report issues and propose improvements in the [ML-Gateway GitHub repository](https://github.com/vulnerability-lookup/ML-Gateway). Consult the repository README for current setup, configuration and API instructions.
